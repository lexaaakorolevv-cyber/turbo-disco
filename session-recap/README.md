# Session Recap v1.0.0

Готовый мод для Geometry Dash **2.2081** и Geode **5.11.1**.

[Скачать local.session_recap.geode](https://raw.githubusercontent.com/lexaaakorolevv-cyber/turbo-disco/session-recap-v1.0.0/session-recap/dist/local.session_recap.geode)

Один пакет содержит сборки для **Windows x64** и **Android 64-bit (arm64-v8a)**.

Закрой игру, скопируй файл в `geode/mods`, запусти Geometry Dash и нажми **Recap** в главном меню или на паузе. На Android можно импортировать пакет через Geode.

Мод показывает активное время, обычные и тренировочные попытки, завершения, новые сохранённые рекорды и предыдущую сессию. Статистика сохраняется локально.

Обе Release-сборки и 13 тестов / 98 проверок прошли. Проверка внутри самой игры пока не выполнялась.
