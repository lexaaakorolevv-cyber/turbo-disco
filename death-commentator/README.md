# Death Commentator 1.1 — реплики на игровом экране

Мод с **крупными текстовыми репликами поверх игрового экрана после смерти** для **Geometry Dash 2.2081** и **Geode 5.11.1** (ветка 5.x). Можно выбрать добрые, нейтральные или обидные комментарии. Обидный режим в версии 1.1 содержит более жёсткие насмешки и мат.

Текст находится в отдельном экранном слое Geode, остаётся видимым при повторной попытке и исчезает при выходе из уровня. Настройки в Comments выбирают тон; сами фразы появляются поверх игры.

## Установка

1. Закрой Geometry Dash.
2. Замени старый `local.death_commentator.geode` новым файлом из `dist` в папке `geode/mods` установленной игры. Не оставляй две версии одного мода. На Android можно импортировать пакет через Geode.
3. Запусти игру. Нажми **Comments** справа в главном меню или на паузе.
4. Выбери **Добрые**, **Нейтральные** или **Обидные**. Кнопка **На экран** сразу показывает реплику крупным текстом поверх игры, в том же виде, как после смерти.

Первый запуск версии 1.1 включает запрошенный экранный пресет: **Обидные**, центр экрана, каждую смерть, интервал 0 секунд и длительность 3,5 секунды. После этого можно изменить настройки — дальнейшие запуски их сохраняют.

Один пакет содержит библиотеки для **Windows x64** и **Android 64-bit (arm64-v8a)**. Для Android 32-bit, macOS и iOS готовых сборок нет. Этот мод устанавливается отдельно от Session Recap; оба можно использовать вместе.

## Три тона

| Тон | Примеры |
| --- | --- |
| Добрые | «У тебя получится!», «Не сдавайся, ты можешь!» |
| Нейтральные | «Попытка завершена», «Смерть на 6%.» |
| Обидные | «Руки из жопы, зато уверенности на три демона.», «Попытка 12. А руки всё ещё из жопы.» |

Есть **69 русских и 69 английских реплик**: по 23 на каждый тон и язык. Реплики зависят от ситуации: смерть в начале, возле конца или в практике. Для платформеров не используются комментарии о процентах и близком финише. Одна и та же реплика выбранного тона и языка не появляется два раза подряд.

Русский текст отображается встроенным шрифтом с кириллицей. Для него не нужны другие моды. Настройки хранятся локально через Geode и сохраняются при закрытии окна.

## Частота и другие настройки

В окне **Comments**:

- **Включён / Выключен** — включение комментариев.
- **Каждую смерть / Каждую 3-ю / 5-ю / 10-ю** — частота. Счётчик начинается заново при входе в уровень.
- **Интервал** — минимальная пауза между репликами: 0, 3, 6 или 10 секунд.
- **RU / EN** — язык фраз. Подписи собственного окна остаются русскими.
- **На экран** — реплика поверх игры. Пример не расходует интервал настоящих комментариев.

В стандартных настройках мода Geode доступны точная частота от 1 до 20, интервал от 0 до 30 секунд, длительность реплики от 1 до 6 секунд, положение **Center / Top / Bottom** и переключатель комментариев в практике.

По умолчанию интервал — **0 секунд**, длительность — **3,5 секунды**, положение — по центру, комментарии в практике включены. Реплика видна сразу, без ожидания анимации появления. Когда заданный интервал ещё не истёк, реплика пропускается без очереди. Новая реплика заменяет предыдущую.

Комментарии появляются после подтверждённой смерти, даже если игра отметила персонажа мёртвым до вызова обработчика. Дополнительная проверка при обновлении кадра подхватывает пропущенное событие. Повторные вызовы в dual-режиме не добавляют вторую реплику; столкновения, которые не привели к смерти, не учитываются. Перезапуск из паузы, завершение уровня, реплеи и тестовые запуски из редактора исключаются. Мод не меняет физику и рекорды игры.

## Сборка

Нужны Geode CLI, SDK **v5.11.1**, CMake **3.25+**. Для Windows — Visual Studio 2022 с MSVC **19.44+** либо Clang **19+** и Windows SDK. Для Android — NDK **r29**.

Windows, PowerShell:

```powershell
$env:GEODE_SDK = 'C:\path\to\geode-sdk'
cmake -S . -B build-win -A x64
cmake --build build-win --config Release
```

Android 64-bit, Bash:

```bash
export GEODE_SDK=/path/to/geode-sdk
cmake -S . -B build-android64 -G Ninja \
  -DCMAKE_TOOLCHAIN_FILE="$ANDROID_NDK_HOME/build/cmake/android.toolchain.cmake" \
  -DANDROID_ABI=arm64-v8a -DANDROID_PLATFORM=android-23 \
  -DGEODE_TARGET_PLATFORM=Android64 -DCMAKE_BUILD_TYPE=Release
cmake --build build-android64
```

Для изменений текстов существующий шрифт содержит ASCII, латиницу, кириллицу и основную пунктуацию. Его можно пересобрать с Pillow и DejaVu Sans:

```bash
python3 tools/build_font.py --font /path/to/DejaVuSans.ttf
```

Лицензия шрифта находится в `resources/font-license.txt`.

## Проверка

Тесты логики не требуют SDK:

```bash
cmake -S . -B build-tests -DDEATH_COMMENTATOR_TESTS_ONLY=ON
cmake --build build-tests
ctest --test-dir build-tests --output-on-failure
```

Проверяются все тона и языки, подстановка процентов/попыток, интервал, частота, отсутствие повторов, переключение настроек и особенности платформеров. Добавлены проверки смертей с заранее выставленными флагами, дублей collision/dual/frame, восстановлений на чекпоинтах и исключения проверочных смертей игры. **24 теста проходят: 16 тестов фраз и 8 тестов цикла смерти**. Проверка запуска в самой Geometry Dash требует установленной игры; в окружении разработки её нет.

После установки проверь в игре:

1. Выбери каждый тон и нажми **На экран** — крупный текст должен появиться по центру игрового экрана, кириллица отображается без пропусков.
2. Включи комментарии, частоту 1 и интервал 0; умри два раза — должна появиться одна новая реплика на каждую смерть.
3. Повтори в dual-режиме — два игрока не должны давать две реплики на один фейл.
4. Перезапусти уровень из паузы — комментарий о смерти не должен появиться.
5. Установи частоту 3 или интервал 6 секунд — реплики должны появляться реже.
6. Перезапусти игру после первого запуска обновления — выбранный тон и частота должны сохраниться.
7. После смерти дождись следующей попытки — реплика остаётся видимой до истечения длительности. Выйди из уровня — реплика должна исчезнуть.
