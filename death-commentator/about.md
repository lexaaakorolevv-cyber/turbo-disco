# Death Commentator

Choose how the game reacts to a fail:

- **Kind**: encouragement and support.
- **Neutral**: calm observations.
- **Roast**: jokes and insults aimed at your gameplay.

Open **Comments** from the main menu or pause screen. The custom settings window
has Russian labels and a preview. There are 69 Russian and 69 English phrases,
with a bundled Cyrillic font, per-level frequency, and a configurable cooldown.

The default is Neutral, with a three-second minimum gap. Set the gap to zero
and frequency to one for a comment on each eligible death. Settings stay local.

Windows x64 and Android64, Geometry Dash 2.2081, Geode 5.11.1.
