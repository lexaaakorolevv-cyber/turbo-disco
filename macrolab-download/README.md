# Macro Lab v0.3.1 — исправление определения уровня

[Скачать готовый .geode](https://raw.githubusercontent.com/lexaaakorolevv-cyber/turbo-disco/de5661339a53ec872f94a36abdf16c00a85df308/macrolab-download/local.macrolab-geode-5.11.1.geode)

Windows x64 / Geometry Dash 2.2081 / Geode 5.11.1. Замените прежний Macro Lab в `geode/mods/` и перезапустите игру.

Исправлена привязка открытого уровня: перед командами/меню, при входе/возврате и в update мод находит живой PlayLayer текущей сцены. Повторная привязка сохраняет поиск и ожидающий ввод. Уходящая сцена и внесценовые PlayLayer исключены; изоляция статистики сохраняется до native exit.

Запустите уровень → F6 → «Сделать макрос». Мод анализирует геометрию, ищет действия через настоящие попытки, записывает найденный ввод и после проверочного повтора автоматически сохраняет JSON solution-ID-HASH. F9 останавливает процесс. Видео не требуется; локальные уровни поддерживаются. Поиск ограничен и не гарантирует решение каждого уровня.

Проверено: CTest8/8 (25 проверок производственной политики привязки), SDK syntax12/12, [успешная Windows-сборка](https://github.com/lexaaakorolevv-cyber/turbo-disco/actions/runs/38571400427), x64 DLL, версия пакета, исправление присутствует в DLL, русский шрифт, ZIP CRC и HTTP200 по прямой ссылке.
