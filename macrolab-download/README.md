# Macro Lab v0.3.0 — сделать макрос автоматически

[Скачать готовый .geode](https://raw.githubusercontent.com/lexaaakorolevv-cyber/turbo-disco/7c45190eca922c671e263d0ff923950d25779613/macrolab-download/local.macrolab-geode-5.11.1.geode)

**Windows x64 / Geometry Dash 2.2081 / Geode 5.11.1.** Удалите старый Macro Lab из `geode/mods/`, скопируйте новый файл и перезапустите игру.

Запустите свой или скачанный уровень, затем **F6 → «Сделать макрос»** (или F10). Мод сам анализирует объекты, выбирает ввод, повторяет обычные попытки и записывает успешное прохождение. После автоматического проверочного повтора результат сохраняется как `solution-ID-HASH.json`. Ручная запись и видео для этого не нужны. F9 останавливает процесс.

Формат: документированный JSON `gdm-macro`, schemaVersion 1, тики/игрок/кнопка/down-up, версии игры и Geode, данные уровня и контрольные состояния. Собственные локальные уровни ID0 отличаются хешем. Подготовка/поиск/проверка/имя файла показаны в HUD. Точный профиль ветвится по одному тику 240Hz.

Это ограниченный экспериментальный поиск с приближённым прогнозом. Он не гарантирует решение каждого уровня. Реальная физика, коллизии и финиш исполняются игрой; награды/рекорды/обычная статистика заблокированы в автоматизированной сессии. Нет teleport/noclip/принудительного завершения. Произвольные возвратные платформерные маршруты и сложные триггеры могут не решиться.

Проверены 7/7 portable CTest, 12/12 CPP по реальным SDK/bindings, native Windows x64 DLL и содержимое пакета, JSON roundtrip+physical replay на независимой модели, русский шрифт, ZIP CRC и HTTP200 прямого файла.
