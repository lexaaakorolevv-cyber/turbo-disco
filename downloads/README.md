# Route Finder 1.13.0 — Windows x64

[Скачать .geode](local.routefinder-windows-x64-v1.13.0.geode?raw=true)

GD 2.2081 / Geode 5.11.1. Замените старый пакет, перезапустите игру и начните новый поиск. Все кнопки: пауза → BOT; в уровне только лучший процент. Лимит 16 CPS на канал сохранён.

Добавлен совместный подбор момента нажатия и длины зажима с сохранением другого игрока. Калибровка проверяет поправки на следующих наблюдениях и восстанавливается после устойчивой смены режима. Архив сохраняет разные маршруты; после застоя повторно проверяются более ранние ветки. Автоматические контрольные точки требуют двух одинаковых повторов: после застоя бот повторяет участок с начала и ищет продолжение после точки. Мгновенного переноса назад нет; при расхождении состояния точка отключается. Пройденный макрос по-прежнему проверяется полным повтором с начала.
