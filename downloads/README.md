# Route Finder 1.9.0 — Windows x64

[Скачать .geode для ПК](https://github.com/lexaaakorolevv-cyber/turbo-disco/raw/refs/heads/route-finder-windows/downloads/local.routefinder-windows-x64-v1.9.0.geode)

GD 2.2081 / Geode 5.11.1. Закройте игру, замените прежний Route Finder в `geode/mods`, перезапустите и проверьте v1.9.0 в BOT. Начните новый поиск: старые макросы/сеансы несовместимы по окружению.

Независимый 2-player, запись/повтор P1/P2, совместный прогноз четырёх комбинаций кнопок и дополнительный поиск выхода из тупиков. Лимит 16 CPS на канал, светлый интерфейс, сохранение лучших участков и обязательный полный повтор с начала. Platformer не поддерживается.

Windows CI: сборка, девять наборов тестов и проверка manifest/PE x64 прошли. Реальный игровой процесс и FPS здесь не проверялись. Поиск не гарантирует произвольный уровень или улучшение в разы.
