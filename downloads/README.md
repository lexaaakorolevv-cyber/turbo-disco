# Route Finder 2.1.0 — Windows x64

[Исходники и инструкция](route-finder-source-v2.1.0.zip?raw=true)

Замените старый local.routefinder .geode и перезапустите игру. GD 2.2081 / Geode 5.11.1+ в ветке 5.x. Не запускайте двух ботов одновременно. Для чистого поиска отключите auto-resume на один запуск.

Новый native-перебор испытывает ввод в игре, поддерживает независимые P1/P2, расширяет окно отката при тупиках и проверяет префикс при полном повторе. 16 CPS на канал. Ускорение экспериментальное и выключено. UI светлый, кнопки только в паузе. Любой уровень пройти не обещается.
