# Route Finder 1.10.0 — Windows x64

[Скачать .geode для ПК](https://github.com/lexaaakorolevv-cyber/turbo-disco/raw/refs/heads/route-finder-windows/downloads/local.routefinder-windows-x64-v1.10.0.geode)

GD 2.2081 / Geode 5.11.1. Закройте игру, замените прежний Route Finder в `geode/mods`, перезапустите. Откройте штатную паузу → BOT и проверьте v1.10.0. Начните новый поиск: старые макросы/сеансы несовместимы.

В игре — только лучший процент. Все кнопки перенесены в паузу; кнопки, панели и линии игрового HUD удалены. Улучшены калибровка форм, разбор смертей конкретного игрока, связки орбов/падов с посадкой и архив альтернативных маршрутов. Solo/shared-dual/независимый 2-player сохранены, 16 CPS на канал.

Нагрузка ниже: 6000 кандидатов и целевые 3 мс прогнозных расчётов на кадр; большие JSON и автосохранение — в фоне. Это кооперативный предел работы, не гарантия FPS.

Windows CI: сборка, десять наборов тестов и проверка manifest/PE x64 прошли. Настоящий игровой процесс, UI и FPS здесь не проверены; произвольный уровень не гарантируется.
