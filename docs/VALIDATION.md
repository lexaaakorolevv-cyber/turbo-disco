# Проверки сборки и ограничение результатов

В доступной Linux-среде выполнены:

- Чистая конфигурация CMake для Android ARM64 с настоящим Geode SDK 5.11.1 и закреплёнными bindings.
- Генерация bindings для GD 2.2081 и компиляция исходников мода NDK r29 / Clang 21.
- Линковка `local.routefinder.android64.so` с официальным `Geode.android64.so`.
- Упаковка `local.routefinder.geode` штатным Geode CLI 3.9.0.
- Сборка portable core GCC 14.2 и `ctest`: успешно.
- Контроль ELF-заголовка готового бинарника: ELF64, shared object, AArch64.
- Повторная конфигурация с автоматической загрузкой закреплённого архива bindings, без локальной подстановки: успешно.

Это подтверждает доступность используемых API, компиляцию, линковку, упаковку и работу тестируемого ядра. Это **не подтверждает прохождение уровня настоящей игрой**: Geometry Dash в этой среде не установлена, GUI/игровой процесс недоступны. Windows и Android32 здесь не собирались.

## Сценарии проверки на устройстве

1. На чистом профиле GD 2.2081 / Geode 5.11.1 открыть простой cube-уровень. Убедиться, что BOT/STOP видны и русские надписи читаются; проверить вход через BOT в меню паузы и на экране завершения и запуск повторного прохода с закрытием штатного экрана.
2. Записать ручное удержание и отпускание, умереть. Загрузить `.best.json`, воспроизвести; проверить совпадение места смерти и отсутствие лишнего удержания после остановки.
3. Записать лёгкое полное прохождение. Убедиться в автоматическом повторе с начала и появлении основного JSON только после второго `levelComplete`.
4. Запустить поиск на коротком уровне с одним препятствием; проверить рост счётчика и сохранение лучшего префикса после смертей.
5. Поставить лимит две попытки и малый лимит времени. Проверить остановку, причину в статусе, `.best.json` и отсутствие выдуманной отметки успеха. Повторить остановку через STOP.
6. Загрузить JSON после перезапуска игры, воспроизвести несколько раз при разных FPS рендера. Состояние должно совпасть или мод должен явно остановиться на рассинхронизации.
7. Проверить отказы для practice, Start Position, platformer, dual, двух игроков, random/item triggers. Внешний reset и переключение неподдерживаемого режима должны отменять работу.
8. Изменить действие, dt или trace в копии JSON: повреждённая структура отклоняется при загрузке, согласованная структура с ошибочной траекторией — при повторе. Поменять ID/версию/хеш/платформу в окружении: загрузка должна быть отклонена.
9. На записанном полном кандидате вызвать смерть или STOP во время проверки: основной успешный файл не должен создаваться или заменяться. Отдельно проверить невозможность записи в каталог и сообщение об ошибке сохранения.

До выполнения этих сценариев на реальной игре пакет следует считать скомпилированной первой реализацией с непроверенной игровой интеграцией. Автоматический поиск ограничен и не имеет гарантии для произвольных уровней.
