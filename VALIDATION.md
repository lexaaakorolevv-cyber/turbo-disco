# Проверки 2.1.0

Новый управляющий слой проверяется отдельно от Geode. Перенесённые модели форм и анализ коридоров проверяются теми же числовыми интерфейсами, которые вызывает адаптер.

- `routefinder2-engine`: реальные границы протокола записи/повтора; точные действия независимых P1/P2; отсутствие обращений к планировщику при записи/повторе; обнаружение рассинхронизации второго игрока; успешный результат требует отдельного полного повтора; смерть/завершение откладываются до service; reset очищает ввод/курсор/часы; лимиты; 16 CPS на внешних 240 Hz часах при двух half steps; проверка half/last/dt; пустой участок не пересчитывается на каждом тике.
- `routefinder2-search`: нижняя по проценту ветка получает попытки при ложном дальнем фронтире; локальная правка сохраняет удачный префикс и другой канал; состояния планировщика возобновляются точно; точка требует двух разных попыток; расхождение отключает точку; повреждённые счётчики отклоняются.
- `routefinder2-persistence`: строгий roundtrip макроса/сеанса; флаг verified из JSON не считается доказательством; отбрасывание неверного игрока и неполной трассы; последний снимок доходит до фонового работника; непроверенный кандидат не попадает в macro.json; восстановление backup.
- `routefinder2-analysis`: цепочки/направление/полосы игроков/границы режимов/условные объекты, полный горизонт форм и dual, независимая wave-развилка с дальним тупиком, ограничение плотной карты, отмена и числовой работник.
- `routefinder2-modes`: переносимые независимые сценарии поддерживаемых форм, взаимодействий и обоих видов dual.

- `routefinder2-native_search`: все четыре joint-mask P1/P2, отсутствие повторной проверки одного немедленного варианта, ограничения CPS/памяти, JSON дерева, свидетели повторения и обнаружение дрейфа, полноценное возобновление остановленного сеанса, остановка при смерти во время повтора префикса. Специальный синтетический тупик имеет 90% и неверную подсказку: расширение возврата должно найти ранний альтернативный ввод. Другой независимый мир требует отсутствующего в модели нажатия: поиск должен найти его через исходы мира и затем пройти отдельный полный проверочный повтор.

Стенды используют переносимый числовой мир, не экземпляр Geometry Dash. Они подтверждают логику ветвления/протокол, но не реальное прохождение уровней.

Реальные API адаптера сверены с закреплёнными bindings GD 2.2081 / SDK 5.11.1. Текущая Windows-сборка и хеши добавляются после CI. Реальные игровой процесс, UI и FPS здесь недоступны.
