# Cube Learner — Windows x64

Бот для **Geometry Dash 2.2081, Geode 5.11.2, Windows x64**, версия мода 0.2.0.
В этой ветке находится Windows-порт с собственными защитными хуками и сборкой
через GitHub Actions. Готовым модом является только `.geode`, созданный успешным
заданием **Build Windows x64**, а не ZIP исходников.

## Скачать после сборки

Откройте Actions → **Build Windows x64** → успешный запуск → Artifacts →
**cube-learner-windows-x64**. В загружаемом ZIP находятся
`local.cube_learner.geode` и `SHA256SUMS.txt`. Сборка не требует слияния ветки в main.

Пакет предназначен для указанной версии GD. Он не подходит для GD 2.2074,
32-битной Windows, Android или macOS.

## Установка и использование

1. Сделайте резервную копию игровых сохранений: реальная защита наград пока
   требует проверки в Geometry Dash.
2. Установите Geode 5.11.2 для GD 2.2081.
3. Скопируйте `local.cube_learner.geode` в `geode/mods` рядом с установленной
   Geometry Dash либо импортируйте локальный мод через интерфейс Geode.
   Перезапустите игру.
4. Откройте обычный classic-уровень. Пауза → **«Бот»** → **«Включить бота»**
   или **«Начать обучение»**. Закройте окно и снимите паузу. Игра сама начнёт
   попытку с начала, без checkpoint-обходов и телепортации.
5. **«Сбросить прогресс»** удаляет обучение только текущего уровня.
6. Выключение немедленно отпускает нажатие и возвращает управление игроку.
   Защита результатов остаётся до полного выхода из уровня.

Интерфейс показывает номер попытки обучения, лучший процент и статус.
На экране есть «ИГРАЕТ БОТ» либо «СЕССИЯ БОТА: БЕЗ НАГРАД».

## Сборка на Windows

Нужны Windows x64, Git, Python 3, CMake 3.25+ и Visual Studio 2022 17.14+
с компонентом **Desktop development with C++**, MSVC **19.44+**, Windows SDK.
SDK Geode использует C++23. Сам алгоритм не зависит от SDK и использует C++17.
Все публичные зависимости загружает скрипт; Python/Pillow для генерации шрифта
не нужен, готовый шрифт включён.

В PowerShell из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build-windows.ps1
```

Либо в PowerShell 7: `./scripts/build-windows.ps1`.
Скрипт выполняет тесты, фиксирует Geode SDK v5.11.2 и bindings
`7407717c307d1cd94461786210b330ab868f4260`, скачивает официальный Geode.lib
и CLI 3.9.0, собирает DLL и проверяет содержимое `.geode`.
Результат: `build/windows-x64/local.cube_learner.geode`.
Если установлен другой совместимый генератор Visual Studio, передайте
`-Generator "Visual Studio 18 2026"` с его точным CMake-именем.

Существующие SDK и bindings можно указать через `GEODE_SDK` и
`GEODE_BINDINGS_REPO_PATH`. Скрипт проверит версии и не будет менять
посторонний checkout. Не включайте `GEODE_DONT_UPDATE_INDEX` с CLI 3.9.0:
SDK передаёт аргумент, который этот CLI уже удалил.

## Windows-защита прогресса

В SDK Geode Safe Mode означает запуск без модов; публичного API игрового
safe mode не найдено. Здесь используются реальные хуки выбранных bindings.
Включение запрещается, если хотя бы один из 34 обязательных защитных/жизненных
хуков отсутствует или выключен.

Сессия помечается как автоматизированная до первого ввода. Обычный completion,
score, процент, статистика, валюта, монеты, награды и достижения блокируются.
Все штатные GD HTTP-запросы также блокируются до выхода из защищённой сессии;
сетевые меню из паузы могут не загрузиться. Запросы, начатые до включения,
не отменяются. Другие моды могут обращаться к сети или сохранениям в обход
перехваченных API; универсальная совместимость не заявляется.

`PlayLayer::incrementJumps` и `GameStatsManager::storePendingUserCoin` встроены
в Windows-код игры и не имеют обычных адресов для Modify. Вместо несуществующих
хуков `WinProgressGuard` удерживает исходные постоянные данные уровня и копию
ожидающих монет. Они восстанавливаются после ввода/кадра, перед сериализацией
уровня/статистики и при завершении выхода. Глобальные честные награды не выдаются.
Координаты, физическая скорость, гравитация и столкновения не изменяются.

Windows-запись обучения использует `MoveFileExW(REPLACE_EXISTING | WRITE_THROUGH)`:
повторное сохранение заменяет предыдущий JSON без предварительного удаления.
Это исправляет отличие `filesystem::rename` от POSIX и поддерживает Unicode-пути.
Уровни хранятся отдельно в `Mod::get()->getSaveDir()/training`. Fingerprint
содержит тип/ID, строку уровня, версии игры/уровня и ключ алгоритма. Изменённые
данные уровня не загружают старую последовательность.

## Как выбираются действия и чему бот учится


`processCommands` вызывается на физических шагах. Адаптер берёт время из
`m_gameState.m_levelTime`; повторные callbacks с тем же временем не продвигают
последовательность. Скорость вычисляется как `Δпозиции / Δигрового времени`.
Переданный движком `dt` не трактуется произвольно как секунды. Первое измерение
имеет нулевую скорость; далее используются наблюдения. Точная работа при timewarp
и совместно с модами тиков требует игрового теста.

Кубовая стратегия ищет опасности и боковые грани блоков на пути текущей высоты.
Для нескольких возможных задержек прыжка она рассчитывает приближённую
баллистическую траекторию AABB и выбирает задержку, которая избегает видимых
препятствий. Начальные оценки импульса и ускорения корректируются по реальным
наблюдениям взлёта и полёта. Расчёт меняет только решение о нажатии; движение
и столкновения всегда рассчитывает Geometry Dash.

Каждый переход нажатия/отпускания записывается вместе с игровым временем. Когда
попытка проходит дальше, её запись становится лучшей. После повторной гибели
без улучшения бот сохраняет ранний удачный участок, а последний прыжок возле
границы прогресса сдвигает раньше/позже фиксированными шагами `1/120` секунды
до `0.1` секунды. Затем снова работает анализ геометрии. Перебор детерминированный;
на пустом участке бот не кликает периодически. Это локальный поиск времени
прыжка, а не нейросеть и не случайный автокликер.

## Границы прототипа

Рабочая стратегия реализована **только для одного куба**. Два канала ввода,
`ModeStrategy` и отдельное описание обоих игроков подготовлены для расширения.
При non-cube, dual, dash или боковой гравитации бот прекращает управление
и отдаёт его игроку. Другие режимы и dual пока не играют автоматически.
Platformer, practice, editor test и встроенные replay не допускаются к обучению.

Порталы, орбы и пады распознаются в снимке. Новые скорость, mini, перевёрнутая
гравитация и режим читаются после фактического перехода. Полного прогнозирования
через портал и отдельной политики активации цветных орбов нет. Пады продолжает
обрабатывать сама игра; вызванное ими движение наблюдается адаптером.

Модель предполагает локальный пол и приближённые статичные прямоугольники.
Она не решает произвольные ямы, цепочки орбов, сложные склоны, движущиеся/вращающиеся
опасности, меняемую триггерами геометрию, маршруты с несколькими режимами и dual.
Размер куба оценивается как `30 * vehicleSize`; hitbox препятствий — AABB, поэтому
шипы и пилы могут оцениваться слишком консервативно. Физика прыжка оценивается
приближённо. Нестандартные силы, временные эффекты и модификации тиков могут
нарушить расчёт и воспроизведение. Очень насыщенные уровни требуют профилирования:
сканирование объектов и перебор траекторий пока не оптимизированы для всех телефонов.

Алгоритм может застрять и не гарантирует прохождение даже кубового уровня.


## Структура

```text
.github/workflows/build-windows.yml  Windows CI и скачиваемый artifact
scripts/build-windows.ps1            локальная/CI сборка
scripts/audit-bindings.py            проверка Windows-адресов обязательных хуков
scripts/verify-package.py            ZIP, metadata, x64 PE DLL и шрифт
src/BotPopup.*, PauseHook.cpp        интерфейс
src/Controller.*, GameplayHooks.cpp  жизненный цикл
src/InputDriver.*                   реальные down/up и очистка
src/GameAnalyzer.*                  наблюдение игры
src/bot/Learner.*                   кубовая стратегия и обучение
src/SafetyHooks.cpp                 защита и проверка хуков
src/WinProgressGuard.*              защита от inline-записи прогресса
src/ProgressStore.*, FileCommit.*    JSON и замена файла в Windows
tests/                             алгоритм и сохранение поверх старого файла
resources/                         русский шрифт и лицензия
```

Полный статус проверок находится в [VALIDATION.md](VALIDATION.md), источники
Windows API — в [SAFETY-API-AUDIT.md](SAFETY-API-AUDIT.md).
